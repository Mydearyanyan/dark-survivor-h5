美术风格：Q版萌系像素。主角=明亮蓝白校服；怪物=暗黑红黑配色+红色发光眼睛（善恶一眼可辨）。
所有素材为透明背景 PNG（RGBA），由总览图裁切 + 纯代码抠图生成，零额外积分。

## 处理脚本（可复现）

- `scripts/crop-sprites.js`：从两张总览图裁切出 13 个单角色（内缩去网格线、教导主任去水印）
- `scripts/matting.js`：纯代码 flood-fill 抠图去白底/浅灰阴影/两腿间白三角
- `scripts/contact-sheet.js`：生成深色棋盘底的素材拼板预览

重新生成：`node scripts/crop-sprites.js && node scripts/matting.js && node scripts/contact-sheet.js`

## 动画与方向规格（v2 最终确认，2026-11-19）

用户试用后确认的新规格，取代上方 v1 静态单帧方案：

### 状态帧数
- **受击：4 帧递进**（必须夸张）：微仰惊呼 → 眼泪飞溅 → 后仰倒地+星星感叹号 → 彻底倒飞+漫天大眼泪星星。参考《热血物语》搞笑受击演出。
- **站立 / 跑步 / 攻击：各 1 帧**。
- 每个角色共 7 个关键帧（3 静态 + 4 受击）。

### 方向（v3 最终：主角真方向，程序镜像仅作补充）
- **主角 8 向（真方向）**：用户否决了纯程序镜像（实测压缩出来的"侧面"只是变窄的正面，看不出朝向）。
  - 关键发现：ImageGen 用 `input_fidelity: low`（不锁死正面参考图）+ 明确指定视角提示词，**能画出真正的背面和 3/4 侧身**。
  - 每个主角单独生成 3 张方向图集（背面 / 左侧 / 右侧，各含站立/跑步/攻击 3 格），存 `assets/sheets/dirs/`。
  - 5 主角 × 3 张 = 15 张（额外积分）。最终 idledown=正面真图、up=真背面、left/right=真侧面；4 个斜向由真方向近似组合。
  - 效果验证：`assets/anim/directions_real_check.png`（班花 8 向，一眼可辨正/背/侧）。
- **怪物/BOSS 4 向**：仍用正面图 + 程序镜像/压缩近似（左上/左下/右上/右下）。因角色小、数量多，方向辨识度需求低。
- **受击 4 帧**：各方向用正面受击图的镜像近似（倒地瞬间方向感弱，可接受）。

### 图集组织
- 每个角色 2 张主图集：`3状态图集`（站立/跑步/攻击 3 格横排）+ `受击图集`（4 帧横排），存 `assets/sheets/`。
- 主角额外 3 张方向图集存 `assets/sheets/dirs/`。
- 裁切抠图后单帧存 `assets/anim/<角色>/<状态><帧>_<方向>.png`，共 534 帧。
  - 主角每帧 8 向（down/up/left/right/downleft/downright/upleft/upright），怪物每帧 4 向（upleft/upright/downleft/downright）。
- 处理脚本：
  - `scripts/build-anim.js`（主图集裁切抠图+镜像，怪物清白块）
  - `scripts/apply-real-directions.js`（主角真方向替换）
  - `scripts/anim-overview.js`（总览拼板）
  - 关键：`matting(im, isMonster)` 怪物清纯白孤岛但保留灰围裙；主角白衬衫不能套用。

### 试点与验证产物
- `assets/anim_overview.png`：14 角色动画总览（每角色 idle/run/attack/hurt1/hurt4 五帧）。
- `assets/anim/directions_check.png`：程序镜像方向对比（失败案例，8 个几乎相同）。
- `assets/anim/directions_real_check.png`：AI 真方向对比（成功，正/背/侧一眼可辨）。
- `assets/sheets/一张游戏角色受击动画精灵图集...06-59-09.png`：受击加强版首图（4帧递进，用户确认夸张度）。
- 全部 534 帧最终素材在 `assets/anim/`，已验证透明干净、状态区分明显、受击夸张、主角真方向。

## 备注

- 除小胖墩外，单角色约280–314px，放大到游戏内较大尺寸会偏糊；如需高清可单独重生成（消耗积分）。
- 素材拼板：`assets/sprites_contact_sheet.png`
- 原始总览图：`assets/一张游戏角色设定总览图...06-29-39.png`（14角色，主角配色版）、`assets/一张暗黑邪恶风格...06-32-07.png`（9怪暗黑版）
- 抠图经验：这批图集是纯白底，比总览图（带灰阴影/水印）好抠得多；`sheet-split.js` 的 flood-fill + 腿部清浅色方案已验证干净。
