# 校园大乱斗 (Campus Brawl)

基于校园设定的「吸血鬼幸存者」类型 H5 小游戏。纯原生 HTML5 + Canvas + JavaScript，无任何外部框架/网络依赖。角色与怪物使用 532 帧原创 Q 版像素动画素材（8 方向、4 种状态、夸张受击演出）。

## 玩法

- **移动**：电脑 `WASD` / 方向键；手机屏幕左下角虚拟摇杆
- **攻击**：全自动，武器自动攻击附近敌人
- **升级**：拾取蓝色经验珠，升级时从 3~4 项强化中任选 1 项（学霸 4 选 1，班花可刷新）
- **敌人**：7 种被「纪律因子」洗脑的同学/老师，打倒后恢复神志
- **BOSS**：5 分钟班主任、10 分钟教导主任，血量低于 30% 进入狂暴
- **目标**：击倒两位主任，等到放学

## 可选主角

| 角色 | 专属技能 | 效果 |
|---|---|---|
| 小胖墩 | 我是奶龙 | 生命 +20%，恢复 +30% |
| 学霸 | 叫我爸霸 | 技能 4 选 1，经验 +10% |
| 体育委员 | 你敢拦我? | 移速 +10%，攻击 +10% |
| 机灵鬼 | 莫挨老子 | 攻速 +10%，暴击 +10% |
| 班花 | 哥哥你好 | 每 3 秒魅惑 1 名敌人 8 秒，升级多 1 次刷新 |

## 武器与被动

- 武器：粉笔头、作业本、教鞭、篮球、圆规（各 8 级）
- 被动：大力Water、风油精、校医包、眼镜、计算器、文具盒（各 5 级）

## 素材与目录

```
index.html                  游戏页面与 UI
game.js                     游戏逻辑（无依赖）
docs/设定文档.md             世界观、属性、角色、怪物、BOSS、技能池
docs/素材清单.md             角色素材映射与动画规格
assets/game-atlas/          游戏用精灵图集（14 张，共约 4.9MB）+ manifest.js
assets/anim/                原始 532 帧透明 PNG（不入库，体积约 43MB）
scripts/build-game-atlas.js 从原始帧生成游戏图集
```

图集生成（需要原始 `assets/anim/`）：

```bash
node scripts/build-game-atlas.js
```

该脚本对每个角色：去透明边 → 清除 AI 生成的矩形边框/网格线 → 等比缩放 → 底部对齐拼入 8 列图集，并输出 `manifest.js`。运行时只需 `assets/game-atlas/`。

## 本地运行

浏览器打开 `index.html` 即可，或启动静态服务器：

```bash
node ../server.js   # http://127.0.0.1:8080
```

## 上架 TapTap

TapTap H5 小游戏要求压缩包解压后为单个文件夹且内含 `index.html`。发布包只需包含 `index.html`、`game.js`、`assets/game-atlas/`（不要带入原始 43MB 素材）。

1. 打包上述三个部分为 zip
2. 在 [TapTap 开发者中心](https://developer.taptap.cn/) 完成开发者认证
3. 创建游戏 → 上传包体 → 填写商店资料、隐私政策、防沉迷、AI 生成内容声明
4. 提交审核（纯广告变现、无内购可走「开放试玩」，无需版号；具体以 TapTap 当前要求为准）

## 技术说明

- 单 Canvas 全屏自适应，支持高分屏（devicePixelRatio）
- 精灵图集 + `drawImage` 分帧渲染，按 y 坐标排序实现前后遮挡
- Web Audio API 合成音效，无音频文件
- localStorage 保存最高纪录
- 键鼠与触摸双输入
