# 暗夜幸存者 (Dark Survivor)

一款纯原生 HTML5 + Canvas 实现的「吸血鬼幸存者」类型（Survivors-like）小游戏，无任何外部依赖与素材，可直接在浏览器运行，也支持打包上架到 TapTap 小游戏。

## 玩法

- **移动**：电脑用 `WASD` / 方向键；手机用屏幕左下方虚拟摇杆
- **攻击**：全自动，武器自动攻击附近敌人
- **升级**：拾取敌人掉落的蓝色经验珠，升级时从 3 项强化中任选 1 项
- **生存**：怪物随时间越来越多、越来越强，每 60 秒出现一次 Boss
- **目标**：活得更久、击杀更多，刷新本地最高纪录

## 武器与强化

- 武器：飞刀、圣光环、雷击、圣书、烈焰（各 8 级）
- 被动：攻击强化、疾行、强健体魄、磁力、急速、护甲、幸运（各 5 级）

## 本地运行

直接用浏览器打开 `index.html` 即可；或在目录内启动任意静态服务器：

```bash
npx serve .
```

## 上架 TapTap

TapTap H5 小游戏要求压缩包解压后为**单个文件夹**，且文件夹内含 `index.html`。本仓库目录结构已符合要求：

1. 将本目录（含 `index.html` 和 `game.js`）打包为 `.zip`
2. 在 [TapTap 开发者中心](https://developer.taptap.cn/) 完成个人主体开发者认证
3. 创建游戏 → 上传该 zip 包体 → 填写商店资料与合规声明
4. 提交审核（一般 1–3 天）

> 提示：纯广告变现、无内购的游戏可走「开放试玩」，无需游戏版号；H5 游戏软著非强制。上架前请以 TapTap 开发者后台当前要求为准。

## 技术说明

- 单 Canvas 全屏自适应，支持高分屏（devicePixelRatio）
- Web Audio API 合成音效，零素材依赖
- localStorage 保存最高纪录
- 同时支持键鼠与触摸操作
